Idea to a private
YouTube draft, in one command.

An unattended pipeline that harvests a trending idea, storyboards it, renders motion clips with Google Flow, strips the watermark, narrates it in Korean, and uploads it as a private draft. The only human step left is hitting publish. A built-in commercial mode turns real product screens into a 30-second vertical app ad with the same engine.

How it works

Seven small CLIs, one chain.

Each stage runs standalone with the same contract — one JSON line on stdout, logs on stderr — or all seven run from the orchestrator.

Studio inspiration → codex storyboard → Google Flow video → delogo → Supertonic Korean TTS → private draft
1

Harvest

Scrape the Studio inspiration feed, rank ideas with codex. Trending fallback.

2

Storyboard

Expand the idea into N scenes and render a PNG per scene.

3

Script

Korean narration, Flow prompts, and YouTube metadata as strict JSON.

4

Video

One Flow clip per scene, then concat, fit, and mux into one MP4.

5

Delogo

ffmpeg wipes the bottom-right Gemini/Flow sparkle watermark.

6

Narration

Supertonic Korean TTS synthesizes the voice and muxes it in.

7

Upload

Private draft via the Studio browser (no OAuth) or the Data API.

Why it holds up

Built for real channels, not a happy path.

Accounts split, entitlements differ, and DOMs drift. Every stage has a proven fallback and a safe default.

Secrets stay out

The one gate

Unattended, right up to publish.

The pipeline automates everything and then stops. It uploads as a private draft and hands you a Studio URL — you review, then flip it private to public. Nothing is ever auto-published.

auto Harvest, storyboard, script
auto Render, delogo, narrate
auto Upload as private draft
you Review & publish
Fallbacks

Two splits, handled.

when the channel account lacks Flow

Render without Flow

build_slideshow.py renders a narrated Ken-Burns video straight from the storyboard stills — no credits, no browser, same downstream chain.

when channel ≠ GCP project account

Upload without OAuth

upload_youtube_studio.py drives the logged-in Studio browser: set the file, title, description, visibility, and save the private draft.

Second output mode

One command, a 30-second app commercial.

The same Flow + Korean-narration engine also renders a vertical app ad — real product screens stay verbatim, Flow supplies only the cinematic B-roll.

Product captures → Google Flow B-roll → concat → ducked music → Supertonic Korean TTS → 1 MP4
🎞

Faithful product UI

Real app screens are shown verbatim as Ken-Burns motion — never fed through a generative model, so text and layout stay crisp. Flow renders only the surrounding atmosphere.
